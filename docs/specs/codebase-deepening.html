Codebase deepening plan

Six places where knowledge leaks out of a shallow module into its callers. For each: what callers repeat today, the deeper interface that absorbs it, the seam, the test.

Baseline main @ d0a3a2f4 (1.91.0) Plan only, no code change Text version: codebase-deepening.md

Vocabulary

ModuleAnything with an interface and an implementation. Function, hook, provider, folder.
InterfaceEverything a caller must know: signature, ordering rules, error modes, invariants.
DepthBehavior a caller gets per unit of interface learned.
SeamPlace where behavior can change without editing that place. Real only with 2+ adapters.
LeverageCallers: one implementation pays back across N call sites.
LocalityMaintainers: fix once, fixed everywhere.

The shape we want

Shallow today, in 6 places
markReady · markFailed · loaded · status · sweepPhotos · …
thin pass-through

Interface nearly as big as body. Rules live in callers, copied N times.

Deep target
useLoad()
load · migrate · gate · persist · retry rules

Small interface, rules inside. Tests cross the same seam as callers.

Rules for every PR

Replace, do not layerTests at new interface replace tests on old shallow modules.
Interface is test surfaceAssert observable outcome. No assertions on internal state or mock call indexes.
Two adapters or no portProduction + test adapter. One adapter is only indirection.
