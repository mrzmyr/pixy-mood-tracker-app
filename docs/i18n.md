## Add strings

- Add new key to [`en.json`](../assets/locales/en.json) and to every other file in [`assets/locales`](../assets/locales) in same PR
- Agents translate new keys by hand. `bun run translate-app` needs Google Cloud credentials that only maintainers have
- Call [`t`](../src/lib/translation.ts) with literal key. Type-check fails on keys missing from `en.json`
- Key built at runtime (for example `` `log_emotion_${key}` ``): use `tDynamic`. Type-check cannot verify it
- Delete key from every locale when you delete it from `en.json`
- `bun run check:locales` compares every locale with `en.json`. CI runs it
- Known gaps: [`scripts/locale-gaps.json`](../scripts/locale-gaps.json). List may only shrink. Never add entries
- After you fill a known gap, run `bun run check:locales --prune`

## Week start

- Calendar and weekly statistics follow device calendar preference through [`useWeekLocale`](../src/hooks/useWeekLocale.ts).
- iOS: Settings > General > Language & Region > First Day of Week ([Apple](https://support.apple.com/guide/iphone/change-the-language-and-region-iphce20717a3/ios)).
- Android 14+: System > Languages & input > Regional preferences ([Android](https://developer.android.com/about/versions/14/features#regional-preferences)).
- Browsers without calendar preference retain date locale's week start.
