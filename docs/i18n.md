## Week start

- Calendar and weekly statistics follow device calendar preference through [`useWeekLocale`](../src/hooks/useWeekLocale.ts).
- iOS: Settings > General > Language & Region > First Day of Week ([Apple](https://support.apple.com/guide/iphone/change-the-language-and-region-iphce20717a3/ios)).
- Android 14+: System > Languages & input > Regional preferences ([Android](https://developer.android.com/about/versions/14/features#regional-preferences)).
- Browsers without calendar preference retain date locale's week start.

## Key order

- Keys in `assets/locales/*.json` stay sorted, so parallel branches add keys at different lines.
- Sort: `bun run i18n:sort` (also part of `bun run fix`).
- CI and `bun run check` fail on unsorted files ([`scripts/sort-locales.ts`](../scripts/sort-locales.ts)).
