Reinstall the preview app, then run Maestro flows on one device.

Usage: bun e2e run (--platform=<ios|android> | --target=<target>) [--paths=<path,...>] [--video]

Options:
  --platform=<ios|android>  Simulator (ios) or emulator (android) of this checkout.
                            CLI creates and boots it.
  --target=<target>         Not supported yet: agent-device `test` cannot run through simlock.
  --paths=<path,...>        Optional. Flow files or folders, comma-separated, relative to repository root.
                            Default: e2e/flows.
  --video                   Optional. Record each flow attempt to recording.mp4 in its artifacts folder.

Behavior:
  Removes the preview app and its data, installs the current build, then runs flows.
  Builds first when cache has no match.
  Shuts down the simulator or emulator after the run if the run booted it.
  Deletes simulators and run files of deleted checkouts first.

Output:
  Flow results on stdout.
  Artifacts folder includes junit.xml.
  --video: video paths on stdout after the run, also when flows fail.
  Failures: e2e_failed names new flows apart from flows in e2e/known-failures.json.

Examples:
  bun e2e run --platform=ios
  bun e2e run --platform=ios --paths=e2e/flows/first-launch.yaml,e2e/flows/entry-cancel.yaml
  bun e2e run --platform=android --paths=e2e/flows/tags.yaml --video

Progress:
  First stderr line: Log: <path>. New log file per run.
  Step lines: Step N/7: <name>. Steps: Resolve device, Reset app, Fingerprint, Build, Install, Start runner, Run flows.
  Last stdout line: PIXY_RESULT status=<ok|error> command=e2e-run [code=<status>] [path=<artifact>]

Errors:
  missing_option          Neither --platform nor --target passed
  conflicting_options     Both --platform and --target passed
  invalid_platform        --platform is not ios or android
  target_not_found        No simlock phone has this target
  simlock_not_configured  SIMLOCK_URL or SIMLOCK_TOKEN not set
  simlock_unreachable     simlock did not answer
  phone_blocked           Phone not reachable from its simlock worker
  device_in_use           Another run holds this device
  path_not_found          One --paths entry does not exist
  e2e_phone_unsupported   --target passed. Phones cannot run flows yet
  app_reset_failed        Preview app was not removed before the run
  e2e_failed              One or more flows failed, read artifacts
  known_failures_invalid  e2e/known-failures.json is not valid
  disk_low                Less than 10 GiB free disk, follow the error fix steps to free disk

Exit codes: 0 pass, 1 failure, 2 usage error
