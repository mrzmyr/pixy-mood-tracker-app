List and reserve devices that can run the preview app.

Usage: bun devices <command> [options]

Commands:
  list     List simulator, emulator, and connected phones
  reserve  Reserve one phone for this checkout
  release  Release this checkout's reservation of one phone
  doctor   Check that Apple's device service answers
  menubar  Open the macOS menu bar app that shows phone reservations

Run `bun devices <command> --help` for details.
